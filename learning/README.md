# Learning index

Start with [the first 28 days](FIRST_28_DAYS.md), then follow [the product work packages](PRODUCT_WORK_PACKAGES.md). Use the [16-term calendar](../docs/ROADMAP.md) to decide when a subject is due.

Learning concepts and languages is the primary goal. For every feature, explain the idea, predict a result, build a small change, investigate a failure and demonstrate a changed input independently.

## Subject paths

| Path | Order and project application |
|---|---|
| Python | Values → control flow → functions → collections → files → modules → tests → service code → analytics |
| Java | College fundamentals → independent classes/collections/error checks → read-only inventory adapter |
| C | Compilation → arrays/pointers → bounds → allocation → cleanup → bounded parsing lab |
| C++ | References/value semantics → RAII → containers → safe processing lab |
| Rust | Ownership/borrowing → typed errors → traits → validator lab → measured integration decision |
| Go | Types/interfaces → goroutines/channels → cancellation → bounded outbound collector |
| SQL | Keys/constraints → joins → transactions → indexes → migrations → isolated service ownership |
| Maths and statistics | Algebra/discrete reasoning → linear algebra/calculus → probability → inference → model evaluation |
| Systems | Linux/OS/networking → debugging → containers → distributed failures → deployment and recovery |
| Data engineering | Contracts → ingestion → quality → lineage → durable workflows → replay and observability |
| AI/ML | Python and maths readiness → EDA → classical ML → time series → deep learning → retrieval/LLMs → evaluation and serving |
| Web and React | Early UI sketches → browser JS/TypeScript → React in T14–T15 → accessible investigation interface |
| Haskell | Small pure-function and fold comparison, at most six hours |

The local project folder additionally retains the original 31 subject files and 404 coaching cards. They are private local reference material and are not included in this public repository. College audit topics remain in the local original tracker rather than being rewritten as duplicate lessons.

Use [source references](../docs/SOURCES.md) for the newly authored roadmap. The [learning issue template](../.github/ISSUE_TEMPLATE/learning-task.md) provides a repeatable structure for future daily tasks.
